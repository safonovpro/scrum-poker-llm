# Навыки Koda — Справочник

Директория `skills/` содержит набор инструментов продуктивности для AI-агента Koda. Это не часть самого приложения Scrum Poker — это набор рабочих методов, которые агент может применять при взаимодействии с пользователем.

Каждый навык — это Markdown-файл `SKILL.md` с YAML-фронтматтером, описывающей имя, описание и параметры вызова. Внутри каждого навыка есть поддиректория `agents/` с конфигурацией `openai.yaml`, определяющей правила вызова.

## Классификация навыков

Навыки делятся на две категории по способу активации:

### Пользовательские (user-invoked)

Вызываются только когда пользователь явно вводит их имя. Агент не может активировать их самостоятельно — нулевая нагрузка на контекст агента, но пользователь должен помнить о них.

| Навык | Назначение |
|-------|-----------|
| **[grill-me](./grill-me/SKILL.md)** | Безжалостное интервью по плану или дизайну, пока не проработана каждая ветка дерева решений. |
| **[handoff](./handoff/SKILL.md)** | Сжатие текущей беседы в документ-передачу, чтобы другой агент мог продолжить работу. |
| **[teach](./teach/SKILL.md)** | Обучение пользователя новому навыку или концепции через серию сессий, с использованием текущей директории как рабочего пространства с сохранением состояния. |
| **[to-questionnaire](./to-questionnaire/SKILL.md)** | Превращение вопроса, на который агент не может ответить сам, в Markdown-анкету для одного человека, который обладает нужными знаниями. |
| **[wait-what](./wait-what/SKILL.md)** | Остановка и повторная подача контекста, если сообщение «не дошло». Агент переформулирует ситуацию на понятном языке, используя терминологию из `CONTEXT.md`. |

### Модельные (model-invoked)

Агент может активировать их самостоятельно при обнаружении подходящих триггеров в разговоре. Имеют описание в фронтматтере, которое всегда загружено в контекст агента — это плата за обнаруживаемость.

| Навык | Назначение |
|-------|-----------|
| **[grilling](./grilling/SKILL.md)** | Интервью пользователя по плану, решению или идее до достижения общего понимания. Строит дерево решений и прорабатывает его по фронтам. |
| **[writing-for-agents](./writing-for-agents/SKILL.md)** | Написание документов для агентов: навыки, `AGENTS.md`/`CLAUDE.md`, любые документы, на которые ссылается агент. |

## Подробное описание каждого навыка

### grill-me — Интервью по плану

**Путь:** `skills/grill-me/SKILL.md`  
**Тип:** Пользовательский  
**Аргумент:** «О чём будем говорить?»

Безжалостное интервью, которое прорабатывает каждый узел дерева решений. Пользователь получает серию вопросов с рекомендуемыми ответами, отвечает, и каждый раунд сужает пространство неопределённости.

### handoff — Передача другому агенту

**Путь:** `skills/handoff/SKILL.md`  
**Тип:** Пользовательский  
**Аргумент:** «Для чего будет использоваться следующая сессия?»

Создаёт компактный документ-передачу с резюме текущей беседы. Включает раздел «рекомендуемые навыки» — какие навыки должен вызвать следующий агент. Чувствительные данные (ключи, пароли) редатируются.

### teach — Обучение

**Путь:** `skills/teach/SKILL.md`  
**Тип:** Пользовательский  
**Аргумент:** «Что вы хотите изучить?»

Самый сложный навык — полноценная система обучения с сохранением состояния. Использует текущую директорию как рабочее пространство:

**Рабочее пространство обучения:**

| Файл/Директория | Назначение |
|-----------------|-----------|
| `MISSION.md` | Причина обучения — реальная цель пользователя. Основа для всех решений. |
| `GLOSSARY.md` | Канонический словарь терминов. Строгий формат: определение + что избегать. |
| `RESOURCES.md` | Кураторский список доверенных источников (знания + сообщества). |
| `learning-records/*.md` | Записи о прогрессе пользователя — аналог ADR для обучения. |
| `lessons/*.html` | Уроки — самодостаточные HTML-файлы, каждый учит одной вещи. |
| `assets/` | Переиспользуемые компоненты уроков (стили, виджеты, симуляторы). |
| `NOTES.md` | Предпочтения пользователя в обучении. |

**Философия:**
- **Знания** — из доверенных источников, а не из параметров агента.
- **Навыки** — через интерактивные уроки с обратной связью.
- **Мудрость** — через реальные сообщества и практику.
- Разделение на **fluency strength** (мгновенное извлечение) и **storage strength** (долгосрочное удержание).
- Зона ближайшего развития — каждый урок должен бросать вызов «чуть выше текущего уровня».

**Форматы документов teach:**
- [MISSION-FORMAT.md](./teach/MISSION-FORMAT.md) — шаблон миссии обучения
- [GLOSSARY-FORMAT.md](./teach/GLOSSARY-FORMAT.md) — формат словаря терминов
- [RESOURCES-FORMAT.md](./teach/RESOURCES-FORMAT.md) — формат списка ресурсов
- [LEARNING-RECORD-FORMAT.md](./teach/LEARNING-RECORD-FORMAT.md) — формат записей о прогрессе

### to-questionnaire — Анкета

**Путь:** `skills/to-questionnaire/SKILL.md`  
**Тип:** Пользовательский

Превращает нерешённый вопрос в Markdown-анкету для одного человека, который обладает нужными знаниями. Интервьюирует пользователя только о «отправке» (кому, что нужно), а не о предмете. Вопросы упорядочены по важности — асинхронная передача означает один проход.

**Структура документа:**
- Цель, от кого, кому, как будут использованы ответы
- Контекст — один абзац для ориентации
- Как отвечать — дедлайн, усилия
- Тематические блоки с вопросами и ответными полями
- Завершающий блок «что-то ещё?»

### wait-what — Повторная подача

**Путь:** `skills/wait-what/SKILL.md`  
**Тип:** Пользовательский

Останавливает работу, если сообщение «не дошло». Агент переформулирует ситуацию на упрощённом техническом английском (ASD-STE100), используя терминологию из `CONTEXT.md`.

### grilling — Интервью по дереву решений

**Путь:** `skills/grilling/SKILL.md`  
**Тип:** Модельный

Агент самостоятельно строит дерево решений и прорабатывает его по раундам. Фронт — это набор вопросов, prerequisites которых уже решены. Каждый вопрос оформляется как:

```
❓ **Q1** - **<заголовок>**: <тело вопроса с вариантами>
➡️ <рекомендуемый ответ>
```

Агент находит факты сам (через подзадачи), решения оставляет пользователю. Сессия завершается, когда фронт пуст — все ветки проработаны, ничего не оставлено предположенным.

### writing-for-agents — Писание для агентов

**Путь:** `skills/writing-for-agents/SKILL.md`  
**Тип:** Модельный  
**Дополнительно:** `skills/writing-for-agents/SKILL-MECHANICS.md`

Справочник по написанию документов, которые потребляет агент: навыки, `AGENTS.md`/`CLAUDE.md`, документы по ссылкам.

**Ключевые концепции:**

- **Контекстные указатели (context pointers)** — ссылки из контекста агента на внешний материал с условием срабатывания. Формулировка указателя решает, когда агент обратится к материалу.
- **Две нагрузки:**
  - **Контекстная нагрузка (context load)** — стоимость всегда загруженного материала в окне агента (токены на каждый ход).
  - **Когнитивная нагрузка (cognitive load)** — стоимость для человека: сколько документов существует и когда за ними обращаться.
- **Принципы:** фронт-загрузка ведущего слова, один триггер на ветку, удаление избыточной идентификации.

**Механика навыков (SKILL-MECHANICS.md):**

- **Модельный навык** — имеет `description`, агент может активировать автономно. Плата — контекстная нагрузка.
- **Пользовательский навык** — `disable-model-invocation: true`, нулевая контекстная нагрузка, но пользователь должен помнить.
- **Навык-маршрутизатор (router skill)** — один пользовательский навык, который перечисляет другие и подсказывает, когда каждый вызывать. Снимает когнитивную нагрузку при большом количестве навыков.

## Как добавить новый навык

1. Создайте директорию: `skills/<name>/`
2. Добавьте `SKILL.md` с YAML-фронтматтером:
   ```yaml
   ---
   name: <имя>
   description: <описание для агента>
   disable-model-invocation: true  # опционально, для пользовательских
   argument-hint: "<подсказка для аргумента>"  # опционально
   ---
   ```
3. Добавьте `agents/openai.yaml` с правилами вызова
4. Если навык требует дополнительных файлов — добавьте их в директорию
5. Обновите `skills/README.md`, добавив навык в соответствующий раздел

```
                    ┌─────────────────┐
                    │  writing-for-   │
                    │   agents        │◄─────── базовый справочник для всех
                    └───────┬─────────┘
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
        ▼                   ▼                   ▼
  grill-me (user)   grilling (model)   writing-for-agents
  (то же, но                           (сам справочник)
   пользовательский)
        │
        │  похожий подход,
        │  но разный триггер
        ▼
   (пользователь выбирает
    между grill-me и grilling)

   teach ────────────────────────────────────►
   (самостоятельная система с рабочим
    пространством и множеством форматов)

   handoff ──► может рекомендовать навыки
   в документе-передаче

   to-questionnaire ──► использует принципы
   из writing-for-agents для структуры
```

## Файлы конфигурации

Каждый навык содержит поддиректорию `agents/openai.yaml` — конфигурация для агента OpenAI/Claude Code, определяющая правила вызова (policy, invocation, триггеры). Конкретное содержимое файлов зависит от конфигурации среды и не является частью публичного интерфейса навыков.
